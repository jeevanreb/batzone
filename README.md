# 🏏 BatZone – Complete Sports Solutions Under One Roof

Welcome to **BatZone**, proudly based in **Hemmadi**, dedicated to providing top-quality sports equipment, premium cricket bat customization & restoration, custom team jerseys, tournament management, and high-end trophies & mementos.

---

## 🌟 Overview

**BatZone** is a modern, high-performance web application built with Next.js, React, Tailwind CSS, and GSAP animations. It showcases all specialized sports services offered by BatZone, including:

- **🏏 BatZone Garage**: Professional cricket bat knock-in, repairs, handle replacement, oiling, polishing, and full bat restoration by master craftsmen.
- **👕 Customized Jerseys**: Custom design and high-quality printing for cricket teams, clubs, schools, colleges, and corporate events.
- **🏆 Trophies & Medals**: Premium customized trophies, mementos, medals, and awards for sports tournaments.
- **📺 Tournament & Event Operations**: Complete tournament setup, pitch preparation, scoring, sound, and LED Wall live streaming.
- **🔨 Live Bidding Auction**: Integrated online player auction platform for real-time team owner bidding.

## 🚀 Getting Started

### Prerequisites

Ensure you have **Node.js** (v18.0.0 or higher) installed on your system.

### Installation

1. Clone the repository or navigate to the project directory:
   ```bash
   cd batzone
   ```

2. Install the project dependencies:
   ```bash
   npm install
   ```

### Development Server

Start the local development server:
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) with your browser to view the application.

### Production Build

To build the application for production deployment:
```bash
npm run build
```

To start the production server:
```bash
npm run start
```
